Mr.Park은 원본에 은색 도장, 유리·실내·휠 재질 변경, 개발용 차량 규격에 맞춘 형상 조정, 조향·회전·등화 연결을 적용했습니다. 원본 번호판·엠블럼과 상표 텍스처는 서비스 화면에서 제외했습니다. 원작자 또는 Khronos와의 제휴·보증을 뜻하지 않습니다.

고화질 모델은 표현용입니다. 특정 실차를 검증한 모델이 아니며, 실제 물리·거리 센서·평가는 기존 개발용 규격을 사용합니다. 성능 우선 모드와 에셋 로딩 중/실패 시에는 직접 작성한 경량 차량을 표시합니다. 상세 고지

미스터팍과 공간 디자인

미스터팍의 브라우저 3D 모델·표정·손 모션, 주차장 장식과 경량 차량은 프로젝트에서 코드로 제작했습니다. 캐릭터의 장식 모션은 AI 제어 정책의 동작이나 학습 성과를 나타내지 않습니다.

콘셉트 아트

캐릭터 소개 이미지는 내장 이미지 생성 도구로 제작한 시안입니다. 실제 시뮬레이션 화면 또는 검증 결과가 아닙니다. 조명·재질·브랜드 방향을 표현하며, 사진 속 실제 차량·주차장을 촬영한 것이 아닙니다.

미스터팍 브랜드 필름

소개 영상은 프로젝트의 콘셉트 이미지를 Wan 2.2 공개 데모에서 영상으로 생성하고 루프 편집한 것입니다. 실제 주행·센서 출력·학습 성능을 촬영한 것이 아닙니다. 모델 가중치는 포함하지 않습니다. 생성 도구·설정·모델 출처

스크롤에 반응하는 주차장 배경도 별도로 생성한 브랜드 필름입니다. 원본 832×480 영상을 Real-ESRGAN으로 1664×960 보정하고 프레임을 보간했습니다. 네이티브 고해상도 촬영이나 실시간 시뮬레이션 영상이 아니며 생성·보정 오차가 있습니다. 모델·도구의 실행 파일은 배포물에 포함하지 않습니다.
