기본은 개인 연습, 학습용 전송은 선택입니다

회원가입은 없습니다. 기록 보관 설정을 켜면 최근 5회 주행을 이 브라우저의 IndexedDB에 저장합니다. 기록 화면에서 삭제하거나 파일로 내려받을 수 있습니다. 브라우저 데이터 삭제 시 기록이 사라지며 다른 기기나 도메인으로 자동 이동하지 않습니다.

‘학습용 기록 전송에 동의하고 켜기’를 선택하지 않으면 주행 기록을 서버로 보내지 않습니다. 한 번 선택하면 다음에 시작한 주행부터 완료 후 자동 전송합니다. 서버 수집이 꺼져 있거나 안내 버전이 바뀌면 전송하지 않습니다. 거절해도 연습·AI 관전·맵 편집을 이용할 수 있습니다. 회원가입과 매회 기여 버튼은 없습니다.

무엇을 왜 수집하나요?

목적은 미스터팍의 저속 주차 정책 연구·학습·오류 분석입니다. 개발용 차량과 가상 주차장 배치, 엔진·센서·정책 버전, 센서 거리, 조작 명령과 적용 결과, 시점·보조 표시 여부, 성공·실패 사유를 수집합니다. 운영자는 정제·검증한 기록만 오프라인 학습과 평가에 사용하며 참여 즉시 모델이 바뀌지는 않습니다.

계정·이름·이메일·GPS·실제 주소·차량번호·맵 이름·원본 주행 ID·원본 실제 시각은 전송 필드에 없습니다. 자유 입력한 장애물 ID도 정해진 번호로 바꿉니다. 실제 공간을 흉내 낸 배치나 주행 패턴의 재식별 위험이 전혀 없다고 보장하지 않습니다. 실주소나 개인정보를 배치·이름에 넣지 마세요.

어디에 얼마나 보관하나요?

Cloudflare R2 비공개 버킷에 보관하고 공개 목록·다운로드를 제공하지 않습니다. 운영자와 학습 담당 팀원만 관리 권한으로 접근합니다. 원본은 업로드 후 30일 만료 대상으로 설정하며 만료 후 학습 추출에서 제외합니다. 실제 물리 삭제는 저장소의 비동기 만료 처리로 지연될 수 있습니다. R2에는 업로드 시각 등 저장소 운영 메타데이터가 남습니다.

운영자가 내려받은 원본·정제 학습 사본도 원본 보관 기한 내에 삭제합니다. 기한이 지난 자료로 새 학습을 하지 않습니다. 이미 학습된 모델은 원시 기록과 별개로 버전 관리하며, 개별 기록의 영향을 즉시 제거하는 재학습은 보장하지 않습니다.

끄기·삭제·문의

전송 설정을 끄면 새 전송을 중단합니다. ‘전송 끄고 이 브라우저의 서버 기록 삭제’는 이 브라우저에 남은 삭제 영수증으로 서버 원본 삭제를 요청합니다. 진행 중 전송을 기다린 뒤 처리하며 요청 제한·네트워크 오류가 나면 미삭제 영수증을 남겨 다시 요청할 수 있습니다. 삭제 요청 정보는 재업로드 차단을 위해 31일 만료 대상으로 보관합니다.

로컬 기록 삭제와 서버 기록 삭제는 별개입니다. 서버 기록을 지우려면 브라우저 데이터를 지우기 전에 위 버튼을 사용하세요. 영수증을 잃으면 계정이 없어서 본인의 기록을 특정할 수 없고 원본 만료 처리를 기다려야 할 수 있습니다. 이미 내려받은 학습 사본의 삭제와 보관 문의는 jinhyeong9568@gmail.com으로 요청하세요. 공개 Issue에는 영수증·원본 기록을 올리지 마세요.

사이트 접속과 공유

웹과 모델 파일은 Cloudflare에서 제공합니다. 네트워크 연결과 남용 방지 요청 제한에 Cloudflare가 IP 주소 등의 접속 정보를 처리할 수 있습니다. IP·User-Agent는 주행 기록에 저장하지 않으며 운영자가 활성화하는 Worker 요청 로그도 비활성화합니다. 플랫폼 내부 보안·운영 로그까지 없다는 뜻은 아니며 완전 익명을 보장하지 않습니다.

방문자 추적용 분석 SDK는 추가하지 않았습니다. 브라우저의 품질·음향·기록 설정은 기기에 저장됩니다. 공유 링크와 맵 파일에는 배치 정보가 포함되므로 실제 주소나 개인정보를 이름에 입력하지 마세요. 링크는 받은 사람이 다시 전달할 수 있습니다.
