서비스·데이터 안내

2026년 9월 17일 · 초기 공개 테스트

현재 주행 기록은 브라우저에만 보관합니다

회원가입은 없습니다. 기록 보관 설정을 켜면 최근 5회 주행을 이 브라우저의 IndexedDB에 저장합니다. 기록 화면에서 삭제하거나 파일로 내려받을 수 있습니다. 브라우저 데이터 삭제 시 기록이 사라지며 다른 기기나 도메인으로 자동 이동하지 않습니다.

실제 사용자 주행 기록은 서버로 업로드하거나 학습에 사용하지 않습니다. R2 저장소는 배포 연결 검증용 합성 파일만 보관합니다. 서버 수집 API도 닫혀 있습니다.

사이트 접속과 공유

웹과 모델 파일은 Cloudflare에서 제공합니다. 네트워크 연결 과정에서 Cloudflare가 IP 주소 등의 접속 정보를 처리할 수 있습니다. 운영자가 활성화하는 Worker 요청 로그는 비활성화했지만, 이것이 플랫폼 내부 보안·운영 로그까지 없다는 뜻은 아닙니다. 이 서비스를 완전 익명이라고 보장하지 않습니다.

방문자 추적용 분석 SDK는 추가하지 않았습니다. 브라우저의 품질·음향·기록 설정은 기기에 저장됩니다. 공유 링크와 맵 파일에는 배치 정보가 포함되므로 실제 주소나 개인정보를 이름에 입력하지 마세요. 링크는 받은 사람이 다시 전달할 수 있습니다.

Cloudflare 개인정보 안내

시뮬레이션의 한계

본 서비스는 개발용 차량·이상적인 위치 정보·가상 거리 센서를 사용한 저속 주차 실험입니다. 실제 차량의 물리·센서·도로를 완전히 재현하지 않으며 실제 운전 지침이나 안전 보장으로 사용하지 마세요. 초기 학습 모델은 실패할 수 있고, 참여 횟수가 성능 향상을 뜻하지 않습니다.

향후 수집 기능

수집 항목 최소화, 네트워크·저장소 로그와의 연결 가능성, 보관·삭제, 요청 제한, 학습 데이터 검증을 확인한 뒤 별도 변경으로 도입합니다. 이 안내는 미래의 자동 수집을 허용하는 동의가 아닙니다. 실제 수집 범위가 달라지면 안내와 필요한 정책·절차를 함께 변경합니다.

문의

프로젝트 문의에 비식별 문제 설명을 남길 수 있습니다. 공개 Issue에 개인정보나 원시 주행 기록을 첨부하지 마세요. 실제 수집 개시 전 비공개 연락 창구를 확정합니다.
