# 아키텍처와 책임 경계

상태: #2/#3 검토 후 **브라우저 실행(옵션 B)**으로 확정했습니다. `engine/`의 TypeScript reset/step 엔진을 `web/src/driving.ts`가 직접 호출합니다. 로컬 기록·맵 링크·실제 MLP 추론·시도 비교를 연결했습니다. `server/`는 개발용 합성 기록 테스트만 수행하며 외부 사용자 수집 서버가 아닙니다. 아래 논리 경계가 모두 별도 서비스로 구현됐다는 뜻은 아닙니다.

## 구성

| 구성 | 책임 | 하지 않는 일 |
| --- | --- | --- |
| 웹 편집기 | 템플릿/장애물/차량 입력과 사전 검증 | 학습 정책·물리 계산 중복 구현 |
| 웹 실행 화면 | 사람 command, 상태·센서 표시, 모드/오류 안내 | 렌더 FPS로 물리 시간 진행 |
| 세션/실행 엔진 | authoritative state, reset/step, 차량·충돌·센서 | 공유 링크의 임의 코드 실행 |
| 제어자 | 사람·계획기·학습 정책의 command 생성 | 다른 차량 모델을 사용해 비교 |
| 기록/평가 | 동일 tick의 관측·행동·상태와 종료/지표 | 정책에 미래 정답 전달 |
| 저장/공유 | 유효 맵 공유, 동의한 기록 저장/삭제 | 모든 연습 기록 자동 수집 |
| 오프라인 학습 | 허가된 데이터 정제·학습·평가·정책 artifact | 사용자 행동마다 즉시 정책 교체 |

한 tick의 계약은 [공통 계약](contracts.md)에 있습니다. 웹은 상태를 보여주는 클라이언트이고, 차량 상태의 기준은 선택한 실행 엔진 하나입니다.

## 실행 위치 선택

A. 기존 엔진 서버 재사용: 브라우저에서 command를 전송하고 서버가 차량/센서/정책을 실행해 상태를 반환합니다. 서버가 ROS를 사용하더라도 브라우저가 ROS를 직접 알아야 할 필요는 없습니다. 세션 격리, 통신 지연, headless/호스팅 비용을 검증해야 합니다.

B. 웹 실행: 기존 저속 모델과 센서 로직을 이식할 수 있다면 브라우저에서 실행합니다. 학습/추론 형식 호환과 서버 학습 환경의 일치성을 검증해야 합니다. Worker는 실제로 UI가 막힐 때 사용합니다.

현재는 B만 구현합니다. A는 검토했던 대안이며 ROS 서버를 배포할 필요가 없습니다. Three.js는 표현 계층이지 센서·제어 정확성을 자동 보장하는 물리 엔진이 아닙니다. 정책은 #11 artifact를 브라우저 CPU에서 지연 로딩해 실행합니다. [추론 경계](mascot.md), [웹 개발 안내](../web/README.md)를 참고합니다.

## 수동/자율 공통 경로

수동 입력이나 정책 출력은 모두 동일한 command 검증·속도/조향 제한·차량 step·충돌·센서·평가 경로를 사용합니다. 모드 차이는 command를 누가 만드는지뿐입니다.

사람이 보는 편집기/탑뷰의 전역 정보와 정책이 받는 observation은 다를 수 있습니다. 그 차이를 기록하고 공정한 학습/비교라는 말로 숨기지 않습니다.

## 세션과 시간

- scenario 수정 후 실행하면 새 immutable snapshot으로 시작합니다.
- engine은 step 번호와 simulation time을 소유합니다. 벽시계는 통신 지연/운영 timeout용으로 따로 기록합니다.
- command 중복/지연과 reset 이전 command를 거부할 기준을 정합니다.
- 연결 끊김 시 command를 무한 유지하지 않고 정지/종료합니다.
- 서버라면 사용자별 world/state가 분리되는지 검사합니다.
- 세션 수/맵 크기/장애물 수/기록 크기에 상한을 둡니다.

## 학습 경계

오프라인 작업은 동일 버전의 환경·센서·제어 계약으로 데이터를 만듭니다. 먼저 기준 제어기/팀원 데이터로 초기 정책을 학습해 사용자 유입 없이도 마스코트가 동작하도록 합니다.

서비스는 검증된 model manifest의 artifact만 고정 버전으로 로딩합니다. 추론 실패를 기록하고 planner fallback은 별도 표시합니다. 반복 참여 데이터 학습과 정책 승격은 [#17](https://github.com/yumina0616/ai-championship-2026/issues/17)입니다.

## 보안·운영

브라우저 입력은 신뢰하지 않습니다. 값/상한/권한을 서버 경계에서도 검사합니다. ROS 제어 채널이나 내부 관리 포트를 공개 인터넷에 무인증 노출하지 않습니다. 사용자가 올린 맵에 shell/코드/파일 경로 실행 권한을 주지 않습니다.

비밀값은 런타임 환경변수/호스팅 Secret으로 관리합니다. 브라우저 번들·저장소·로그에 서버 키를 포함하지 않습니다. 구체 저장소와 동의/삭제 처리는 [데이터와 학습](data-learning.md)을 따릅니다.

재생은 저장 state 표시이며 실시간 제어 재실행/실차 재현성과 다릅니다. 실제 시스템 안전성은 이 시뮬레이션만으로 입증할 수 없습니다.
