## 검증 순서

1. 차량 1대와 벽 1개를 실행하고 reset 직후 pose를 기록합니다.
2. 낮은 속도로 직진·좌/우 조향·후진·정지를 각각 실행합니다.
3. 벽을 이동시켜 센서 수치가 바뀌는 원시 측정값을 기록합니다.
4. 웹 버튼에서 command를 보내고 pose/센서 결과를 화면에 표시합니다.
5. 연결 끊김·reset·두 세션을 검사합니다.
6. headless 또는 선택한 호스팅에서 같은 경로가 가능한지 확인합니다.
7. 로그/영상/commit과 실패한 항목까지 Issue에 첨부합니다.

첫 왕복은 화려한 화면이 필요 없습니다. mock으로 통신 화면만 채운 것을 재사용 성공으로 판정하지 않습니다.
