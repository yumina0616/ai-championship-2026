# 공개 배포·제출 체크리스트

담당: JH-9568 / yumina0616 공동, Issue [#15](https://github.com/yumina0616/ai-championship-2026/issues/15). 체크는 실제 검증한 뒤 채웁니다. 아래는 **공개 배포 최종 확인표**이므로 로컬 자동 테스트 통과만으로 체크하지 않습니다. 로컬 구현/검증과 남은 결정은 [배포 전 인수인계](pre-deploy.md)를 참고하세요.

## 실제 기능

- [ ] 새 브라우저에서 서비스 URL을 열 수 있다.
- [ ] 환경 템플릿·장애물 편집·입력 오류 안내가 동작한다.
- [ ] 지원 차량 제원·단위·지원 범위를 표시한다.
- [ ] 직접 운전·전후진·정지·충돌·reset이 동작한다.
- [ ] 장애물 위치가 바뀌면 가상 센서 수치가 바뀐다.
- [ ] 마스코트는 실제 학습 artifact로 command를 생성한다.
- [ ] 같은 초기조건에서 두 모드를 실행할 수 있다.
- [ ] 기록/결과/재생이 실제 실행과 일치한다.
- [ ] planner/mock/playback과 learned live를 구별한다.
- [ ] 실패/미지원 환경/추론 오류가 숨겨지지 않는다.
- [ ] 3명 이상 사용성 확인 결과와 수정 사항을 기록했다.

## 기술·학습

- [ ] engine/차량/sensor/contract/model/data/evaluator 버전을 고정했다.
- [ ] 좌표·step·충돌·센서·종료 테스트와 웹 build가 통과한다.
- [ ] 학습/평가 맵 분리, seed와 전체 분모를 확인했다.
- [ ] 성공률·충돌률·오류·오차 등 실제 평가표와 실패 사례가 있다.
- [ ] 모델 없는 경우 학습 정책이라고 표시하지 않는다.
- [ ] 사람의 탑뷰/도움과 정책 관측 차이를 기록했다.
- [ ] 실제 실행 명령·환경·코드 commit·artifact checksum이 남아 있다.

평가 결과 기록 양식: 실행일 / 코드 commit / 환경·모델·데이터 버전 / 평가 맵·seed 목록 / 시도 수 / 성공·충돌·timeout·오류·개입 / 오차·시간 / 한계 / 원본 결과 링크. 미측정 값은 미측정으로 표기합니다.

## 데이터·권리

- [ ] 기여 기본값은 해제이고 거절해도 연습할 수 있다.
- [ ] 동의하지 않은 연습 기록을 학습 목적으로 업로드하지 않는다.
- [ ] 공개 맵과 비공개 운전 기록의 권한이 분리되어 있다.
- [ ] 목적·보관 기간·삭제·철회·모델 반영 한계를 안내한다.
- [ ] 비밀키·개인정보·비공개 코드가 저장소/화면/로그에 없다.
- [ ] 기존 코드·데이터·모델·폰트·캐릭터·에셋 사용 권한을 확인했다.
- [ ] 프로젝트 라이선스를 공동 결정하고 필요한 고지를 반영했다.

## 운영

- [ ] 실제 엔진이 공개 웹에서 연결된다. 개발자 PC에만 의존한다면 가동·네트워크·장애 위험을 해소했다.
- [ ] 두 세션이 서로 차량 상태/command를 섞지 않는다.
- [ ] 연결 끊김·focus 이탈·재접속·세션 만료 시 안전하게 정지/종료한다.
- [ ] 서버 입력 검증, 세션/요청/맵/기록 상한과 접근 권한이 있다.
- [ ] 최대 동시 사용자 가정과 실측 부하, 실패 화면·대기 방식을 기록했다.
- [ ] 운영 비용 상한, 모델/서비스 rollback, 장애 대응 담당을 기록했다.
- [ ] 9/21–10/17 공개 접속 유지 계획과 점검 담당을 정했다.

운영 기록 양식: 서비스 URL / 프론트 호스팅 / 엔진 호스트 / 저장소 / 월 또는 심사기간 비용 상한 / 동시 세션 상한 / health 확인 방법 / 재시작 방법 / 주 담당·백업. 자격 증명은 쓰지 않습니다.
