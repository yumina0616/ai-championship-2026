# 로컬 파일 공유와 데이터 선택

구현 범위는 #13 중 **로컬 파일 공유·개인 연습·삭제**입니다. 서버 공유 링크/기여 업로드/타인 private 기록 접근 제어/동의 철회 API는 구현하지 않았고 #13을 닫지 않습니다.

## 맵만 전달

편집기 → 맵 파일 내보내기 → 포함 항목 확인 → 확인 후 맵 다운로드 순서입니다. 기본 공유 이름은 `공유 주차장`으로 바꿔 원래 이름이 자동 노출되지 않게 합니다. 원하는 이름으로 바꿀 수 있지만 주소·차량번호·식별정보를 쓰지 마세요. 원래 편집 맵 이름은 유지됩니다.

파일에는 version/name/start/goal/obstacles만 담깁니다. Episode, 센서 로그, 날짜, 계정, consent는 넣지 않습니다. 취소/Escape 시 파일을 만들지 않습니다. 받는 사람은 편집기의 맵 파일 열기로 입력 검사를 거쳐 복원합니다. 직접 전달한 파일은 서비스가 회수하거나 지울 수 없습니다.

## 보관 선택

- **이 브라우저에 주행 기록 보관**은 초기 켜짐이며, 끄면 다음 실행부터 Episode를 만들거나 저장하지 않습니다. 운전·센서·평가 기능은 동일합니다. 기존 보관분 삭제와는 별개입니다.
- 선택은 localStorage `parkside-record-locally`에 on/off 한 값으로 보관합니다. 저장소 차단 시 이번 탭에서만 적용됨을 안내합니다.
- 학습 기여는 아예 제공하지 않습니다. 업로드 동의 UI를 흉내 내거나 동의한 것처럼 기록하지 않습니다. 로컬 파일/연습 거절 여부와 무관하게 사용할 수 있습니다.
- 최근 5개 IndexedDB 기록과 마지막 메모리 기록은 개별/전체 삭제가 가능합니다. 전체 삭제에는 확인이 필요합니다. 다운로드한 파일과 다른 사람이 받은 사본은 별도로 삭제해야 합니다.
- 브라우저 보관·유실·파일 검증은 [로컬 기록 계약](local-episodes.md)을 따릅니다. 서버 보관 기간·익명 삭제 ID·학습 반영/철회 한계가 정해지기 전에는 업로드를 켜지 않습니다.

테스트: `cd web && npm test -- tests/privacy.spec.ts tests/maps.spec.ts tests/episodes.spec.ts`. 네트워크 검사는 기록 끔 연습과 파일 열기에서 POST/PUT/PATCH가 없음을 확인합니다. 향후 배포 인프라 자체의 접속 로그까지 없다는 보장은 아닙니다.
