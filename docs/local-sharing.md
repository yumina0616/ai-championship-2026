# 로컬 파일 공유와 데이터 선택

이 문서는 #13 중 **로컬 파일·맵 포함 URL 공유·개인 연습·삭제와 개발용 합성 API**를 설명합니다. 후속 비공개 R2 서버 수집은 [수집 계약](collection.md)을 참고하세요. [로컬 API 안내](../server/README.md)의 합성 테스트와 실제 공개 수집을 구분합니다.

## 맵만 전달

편집기 → 맵 파일 내보내기 → 포함 항목 확인 → 확인 후 맵 다운로드 순서입니다. 기본 공유 이름은 `공유 주차장`으로 바꿔 원래 이름이 자동 노출되지 않게 합니다. 원하는 이름으로 바꿀 수 있지만 주소·차량번호·식별정보를 쓰지 마세요. 원래 편집 맵 이름은 유지됩니다.

파일에는 version/name/start/goal/obstacles만 담깁니다. Episode, 센서 로그, 날짜, 계정, consent는 넣지 않습니다. 취소/Escape 시 파일을 만들지 않습니다. 받는 사람은 편집기의 맵 파일 열기로 입력 검사를 거쳐 복원합니다. 직접 전달한 파일은 서비스가 회수하거나 지울 수 없습니다.

같은 미리보기에서 **확인 후 링크 만들기**를 누르면 맵 JSON을 UTF-8/base64url로 인코딩한 `#map=...` 링크가 나옵니다. 암호화/권한 보호가 아니며 누구에게나 재전달할 수 있습니다. URL query는 제거하고 맵 최소 필드만 다시 검증해 담습니다. fragment는 HTTP 요청 본문/경로로 보내지 않지만 브라우저 히스토리·복사받은 사람에게 남고 페이지 스크립트가 읽을 수 있습니다. 외부 분석 스크립트를 추가하기 전에 유출 경계를 재검토해야 합니다.

수신 화면에서 이름/장애물 수·포함 항목을 확인하고 **확인 후 이 맵 적용**을 눌러야 현재 편집 내용/주행 snapshot을 바꿉니다. 링크만 열면 자동 운전/업로드하지 않습니다. 16,000자 초과/손상/지원하지 않는 배치는 거부하며 큰 맵은 파일로 공유합니다. localhost 링크는 같은 PC에서만 열리므로 공개 공유에는 향후 배포 URL이 필요합니다. 서버 단축 링크나 회수/만료 기능은 없습니다.

## 보관 선택

- **이 브라우저에 주행 기록 보관**은 새 방문자에게 초기 꺼짐입니다. 첫 운전 요청 시 선택 창에서 켤 수 있으며, 끄면 다음 실행부터 Episode를 만들거나 저장하지 않습니다. 운전·센서·평가 기능은 동일합니다. 기존 보관분 삭제와는 별개입니다.
- 선택은 localStorage `parkside-record-locally`에 on/off 한 값으로 보관합니다. 저장소 차단 시 이번 탭에서만 적용됨을 안내합니다.
- 학습용 서버 전송은 별도 선택이며 기본 OFF입니다. 파일 공유/로컬 기록과 분리하고 동의 없이 업로드하지 않습니다. 서버 삭제는 로컬 기록 삭제와 다른 기능입니다.
- 최근 5개 IndexedDB 기록과 마지막 메모리 기록은 개별/전체 삭제가 가능합니다. 전체 삭제에는 확인이 필요합니다. 다운로드한 파일과 다른 사람이 받은 사본은 별도로 삭제해야 합니다.
- 브라우저 보관·유실·파일 검증은 [로컬 기록 계약](local-episodes.md)을 따릅니다. 서버 보관 기간·익명 삭제 ID·학습 반영/철회 한계가 정해지기 전에는 업로드를 켜지 않습니다.

테스트: `cd web && npm test -- tests/privacy.spec.ts tests/maps.spec.ts tests/episodes.spec.ts`. 네트워크 검사는 기록 끔 연습과 파일 열기에서 POST/PUT/PATCH가 없음을 확인합니다. 향후 배포 인프라 자체의 접속 로그까지 없다는 보장은 아닙니다.
