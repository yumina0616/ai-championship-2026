# 제품 계획

상태: 제출 MVP 기획. 기능은 아직 구현되지 않았으며 실측 사용자·학습 성과는 없습니다.

## 한 문장

내 상황과 비슷한 주차장을 만들어 직접 연습하고, 같은 공간에서 AI 마스코트의 주차를 관찰·비교하는 참여형 웹 시뮬레이터.

## 문제와 검증할 가설

대상은 주차 공간의 폭·기둥·차량 크기 때문에 특정 상황이 부담스러운 운전자입니다. 정해진 영상과 다른 배치에서 무엇이 달라지는지 안전하게 반복해볼 수 있는 경험을 제공합니다.

이 문제는 사용자 인터뷰로 추가 확인해야 합니다. 대체 서비스가 전혀 없다는 주장, 실제 운전 실력 향상, 사고 예방 효과는 아직 입증하지 않았습니다. 3명 이상에게 상황 구성→연습→결과 확인을 시켜 막힌 지점·이해도·재사용 의향을 기록하는 것을 첫 제품 검증 목표로 둡니다. 이는 시장 통계가 아닙니다.

두 번째 대상은 저속 주차 정책을 실험하는 개발자입니다. 다양한 배치의 관측·행동·실패 기록을 같은 계약으로 확보할 수 있는지 검증합니다. 이것이 실차 학습용으로 곧바로 적합하다는 뜻은 아닙니다.

## 사용자 흐름과 두 모드

| 단계 | 사용자 행동 | 제품이 제공해야 하는 것 |
| --- | --- | --- |
| 환경 만들기 | 직각주차 템플릿 선택·장애물 편집 | 실제 단위 치수·유효성 안내 |
| 차량 확인 | 지원 차량 선택 | 길이·폭·축간거리·한계 설명 |
| 직접 운전 | 조향·전후진·재시도 | 실제 차량 실행·센서·충돌·결과 |
| 마스코트 운전 | 같은 환경에서 관전 | 실제 정책 실행·버전·실패 이유 |
| 결과 보기 | 경로·오차·성공 비교 | 동일 조건 여부와 개입 여부 |
| 공유/기여 | 맵 공유, 선택적 기록 업로드 | 공개 범위·동의·삭제 방법 |

직접 운전과 마스코트 운전은 선택 사항입니다. 사용자가 AI 지시를 따라야만 끝나는 튜토리얼 게임으로 바꾸지 않습니다.

MVP에서는 지원 차량 1종만 정확히 연결합니다. 장기적으로 본인 차종을 고르는 경험을 지향하되, 외형만 바꾸고 같은 제어 모델을 모든 차량에 맞는 것으로 표기하지 않습니다.

## 마스코트

가칭인 미래의 초보 운전자 캐릭터를 사용합니다. 사용자들이 만든 환경을 함께 도전하는 친근함을 제공하되, 캐릭터 대사와 실제 제어는 분리합니다.

- 지금 실행 중인 정책 버전과 지원 범위를 보여줍니다.
- 학습 정책, 계획기, 기록 재생, 모의 동작을 명확히 구분합니다.
- 기여 횟수는 참여 지표입니다. 성능은 고정 평가에서 측정한 별도 지표입니다.
- 초기 모델은 팀원이 준비한 허가된 데이터/기준 rollout으로 학습합니다.
- 사용자 데이터 반영은 정제→학습→평가→승격 순서이며 자동 향상을 약속하지 않습니다.

## 센서와 AI의 실체

가상 차량의 거리 센서는 환경 기하와 센서 위치/방향에서 실제 측정값을 계산합니다. 장애물을 옮기면 결과가 바뀌어야 합니다. 정해진 좌표를 탐지한 것처럼 애니메이션만 연출하지 않습니다.

Physical AI 요소는 관측→제어 행동→차량/환경 변화→새 관측의 폐루프입니다. 낮은 속도의 제한된 모델을 사용하며 카메라 비전, SLAM, 실제 차량 시험을 구현했다고 주장하지 않습니다. 시뮬레이터의 이상적 자기 위치를 사용한다면 명시합니다.

경로 계획기는 유용한 기준이지만 학습한 정책과 같지 않습니다. 서비스 핵심 AI는 실제 학습된 주차 제어 정책입니다. LLM 안내문은 필수가 아닙니다.

## 지도 대신 무엇을 만드는가

처음에는 치수가 있는 주차장 템플릿을 복제하고 기둥·벽·옆 차량을 자유 배치합니다. 실주소를 요구하지 않습니다. 지도/사진은 정확한 실내 기하를 자동 제공하지 않으므로 지도 연동을 핵심 선행 작업으로 두지 않습니다.

배치 유효성(차체 겹침·범위 등)과 실제 도달 가능성은 다릅니다. 좁거나 불가능한 맵에서는 실패/미지원임을 알려야 하며, 항상 완벽히 주차할 것을 약속하지 않습니다.

## 성공 기준

- 제품: 처음 온 사용자가 별도 설치 없이 환경을 만들고 두 모드를 구분하여 사용할 수 있다.
- 시뮬레이션: 센서·제어·충돌·종료 판정이 정해진 작은 테스트에서 검증된다.
- 학습: 실제 학습 artifact가 실행되며 학습에 쓰지 않은 환경에서 전체 성패가 보고된다.
- 데이터: 동의한 기록만 업로드되고 관측/행동/실패/버전이 정렬된다.
- 설명: 데모와 결과가 실제 동작·지원 범위와 일치한다.

달성하지 못한 항목은 미완료로 남깁니다. 예쁜 장면이나 선별 성공 영상만으로 성능을 주장하지 않습니다.

## 제외와 확장

MVP 제외: 실제 지도 복원, 임의 차종 일반화, 실시간 온라인 학습, SLAM, 고속 주행, 실차 안전 보장, 대형 커뮤니티, 고품질 캐릭터 제작 의무.
